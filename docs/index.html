The missing control panel for macOS

Adjusts brightness, color warmth, volume, pointer speed, and window position from one sidebar. These are settings macOS does not otherwise provide.

Plus control mapping for DualSense, Siri Remote, and MX Master when you want them.

Install

One line, then grant what you use.

$ brew install --cask whitesticker/controlbox/controlbox

Open Control Box, then turn on the permissions it asks for in System Settings → Privacy & Security. Restart the app if macOS asks you to.

The first time you open it, you may need to right-click the app and choose Open. Developers can also build it from the source code — see the README.

Privacy

Control Box stays on your Mac. Nothing is uploaded.

Nothing you type, click, or say is ever sent anywhere. Control Box only looks at Bluetooth to see which devices are connected. Every permission it asks for is used only for the features on this page — nothing more.
